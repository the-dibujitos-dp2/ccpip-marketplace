# Idiomas: espanol e ingles

RF-95 (CCPIP-98), RF-135 (CCPIP-265) y RNF-44: toda funcion entregada, con sus avisos y errores,
se usa en espanol y en ingles. El espanol es el idioma original y el de respaldo.

## Textos de la interfaz (frontend)

La interfaz usa [react-i18next](https://react.i18next.com). Los textos viven en dos diccionarios
con las mismas claves:

- `frontend/src/i18n/es.json`
- `frontend/src/i18n/en.json`

**Ningun texto visible se escribe directo en el JSX**, tampoco los `aria-label`, `title`, `alt` ni
los `placeholder`. Un texto nuevo se agrega a ambos diccionarios en el mismo PR:

```jsx
import { useTranslation } from 'react-i18next'

export default function Ejemplo({ unidades }) {
  const { t } = useTranslation()
  return <p>{t('carrito.resumen', { unidades })}</p>
}
```

En `es.json`: `"carrito": { "resumen": "{{unidades}} unidades" }`
En `en.json`: `"carrito": { "resumen": "{{unidades}} units" }`

Reglas:

- Las claves se agrupan por pantalla o componente (`cabecera.*`, `pie.*`, `productor.nav.*`).
- Variables con `{{nombre}}`, iguales en ambos idiomas. La prueba `i18n.test.jsx` falla si una
  clave falta en un idioma, si un texto esta vacio o si las variables no coinciden.
- Una clave que falte en ingles se muestra en espanol, nunca como la clave cruda.
- Fechas, precios y cantidades se formatean con `formato.js`, que sigue el idioma activo. Los
  precios van en soles en ambos idiomas (multimoneda fuera de alcance, CCPIP-99).
- Las pruebas corren en espanol; cada una vuelve a espanol al terminar (`test/setup.js`). Para
  probar ingles: `await i18n.changeLanguage('en')`.

## Contenido del servidor (backend)

Los textos que escriben los productores y la Camara (productos, historias, tiendas, comunidades,
lineas y unidades) no van en los diccionarios: su version en ingles vive en la tabla `traduccion`
(ver `docs/modelo-de-datos.md`). CCPIP-166, CCPIP-357 y CCPIP-358.

- El frontend manda `Accept-Language` en cada peticion (`api/http.js`) y el catalogo publico
  responde con el contenido **aprobado** en ese idioma (`Content-Language`).
- Lo que no tiene traduccion aprobada se muestra en su original en espanol.
- Al cambiar de idioma, las paginas del catalogo se vuelven a montar para pedir el contenido otra
  vez (`App.jsx`).
- Los errores de la API llegan con un `code`; el texto que ve el usuario sale de `errores.*` en
  los diccionarios (`i18n/errores.js`).
- Una traduccion cuyo original cambio queda desactualizada y deja de servirse: se muestra el
  original (CCPIP-373).
- La ficha (`/api/productos/{id}`) y la tienda (`/api/tiendas/{id}`) traen `traducciones`: por cada
  campo traducido, su `origen` (`COMUNIDAD` o `AUTOMATICA`), si esta `vigente` y su `original`. La
  pantalla lo etiqueta como "Traducido por la comunidad" o "Traduccion automatica" y ofrece "Ver
  original"; si no esta vigente, avisa que se muestra el original (CCPIP-171).

### Traduccion automatica (CCPIP-147)

Quien traduce el contenido de las tiendas sigue pendiente de definir con el cliente. Por eso la
traduccion automatica va detras de la interfaz `TraductorAutomatico` y se elige con
`ccpip.traduccion.proveedor` (variable `CCPIP_TRADUCCION_PROVEEDOR`):

- `ninguno` (por defecto): responde 503 `TRADUCCION_NO_DISPONIBLE` y el contenido queda en su
  original. El editor avisa que no esta disponible.
- `simulado`: **solo pruebas**. No traduce: antepone `[simulado en] ` al original.

No hay ningun proveedor real integrado. El productor la pide desde PW-04 (producto e historia) y
PW-08 (tienda) con `POST /api/productor/productos/{id}/traducciones/en` y
`POST /api/productor/tienda/traducciones/en`. La traduccion queda pendiente hasta que la publica
con `.../aprobar`, donde puede corregir cada texto.

## Glosario

Terminos ya usados en el prototipo (CW-03-EN) y en los diccionarios. Mantenerlos para no mezclar
traducciones de un mismo concepto.

| Espanol | Ingles |
|---|---|
| Punto de acopio | Collection point |
| Comunidad | Community |
| Tienda | Store |
| Productor | Producer |
| Minorista / Mayorista | Retail / Wholesale |
| Origen verificado | Verified origin |
| Lote | Batch |
| Carrito | Cart |
| Ingresar / Cerrar sesion | Log in / Log out |
| Novedades | New arrivals |
